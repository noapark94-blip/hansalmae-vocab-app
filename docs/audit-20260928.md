- 실제 학생·선생님 계정으로 운영 시험을 제출하거나 실제 기기 여러 대로 대전하지는 않았다. 인증 이후 브라우저 테스트는 모의 API/세션을 사용했다. iPhone·Android 분기 검증은 Chromium 시뮬레이션이며 실제 Safari/PWA 키보드 검증을 대신하지 않는다.

- RLS 정책 없는 25개 테이블은 서버 전용 접근을 위한 차단 상태다. is_staff는 현재 사용자만 확인하는 기존 SELECT 정책용 함수이므로 advisory만 보고 실행권한을 일괄 제거하지 않았다.
