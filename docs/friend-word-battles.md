# 친구와 단어 대전

내 학습의 **친구와 단어 대전**에서 정확한 학생 아이디로 친구를 요청합니다. 상대가 수락하면 초대 코드 없이 대전을 신청할 수 있습니다. 중등·고등·수능 Day 범위 또는 두 학생에게 공통으로 배정된 학교 단어장을 선택합니다.

영어→한글, 한글→영어, 혼합 중 선택하며 4지선다 10·20·30문제 중 선택합니다. 기본값은 10문제입니다. 둘 다 준비하면 3초 뒤 시작합니다. 문항별 10초, 두 학생이 제출하거나 시간이 지나면 정답을 공개합니다. 정답 수 우선, 동점은 정답을 맞힌 문항의 총 서버 측 경과 시간으로 판정합니다. 네트워크 지연은 경과 시간에 포함됩니다. 문항 순서는 같고 상대의 보기 순서는 반대입니다. 중도 나가기는 패배로 기록합니다. 두 기기가 모두 연결을 잃으면 2분 뒤 만료됩니다. 대기 신청도 2분 뒤 만료됩니다.

결과에는 점수, 정답 풀이 시간, 다시 익힐 단어와 기존 예문, 재대전 버튼을 표시합니다. 대전의 틀린 단어는 해당 대전 결과에서 복습하며 기존 오답노트에는 기록하지 않습니다. 보상은 기존 월간 포인트와 누적 경험치에 합산됩니다. 오프라인 친구에게도 신청할 수 있지만 앱을 열어 수락해야 합니다. 외부 푸시 알림은 보내지 않습니다.

## 구현

- `public/friend-battle.js`, `public/friend-battle.css`: 기존 학생 앱 안의 화면. 별도 페이지나 하단 탭을 추가하지 않습니다. 친구 화면 7초, 대전 1.4초, 다른 학생 화면 10초 간격으로 조회합니다. 숨겨진 브라우저에서는 조회를 멈춥니다. 이전 요청·계정의 응답은 폐기합니다.
- `supabase/functions/word-battle`: JWT를 Auth에서 검증하고, 활성 학생 세션의 SHA-256 토큰 해시·만료·프로필을 확인합니다. `verify_jwt=false`는 기존 앱의 요청 본문 토큰 인증을 위한 설정이며 모든 action에 동일한 사용자 인증을 적용합니다. actor는 요청 입력을 사용하지 않습니다.
- 질문·정답은 서버에서 생성하고 저장합니다. 클라이언트는 현재 문제만 받으며 정답 ID는 공개 시점 이후에만 받습니다. 답변 재전송은 첫 제출을 덮어쓰지 않습니다. 같은 학생의 동시 대전 신청은 advisory lock으로, 각 대전 진행은 row lock으로 직렬화합니다.
- 친구와 게임 테이블은 RLS와 클라이언트 권한 회수로 기본 거부합니다. 서비스 전용 invoker RPC만 허용하며, **RLS 정책이 없는 것은 의도한 기본 거부 설정**입니다. 차단은 친구 관계를 해제하고 양방향 검색·신청을 막습니다.
- 모든 학교 단어장 신청은 두 학생의 현재 공통 배정을 서버에서 재검증합니다. 중복 영어 및 여러 정답이 가능한 동일 프롬프트는 출제에서 제외합니다. 선택한 문제 수를 만들 수 없는 범위는 범위 확장 또는 문제 수 축소를 안내합니다.

## 검증

`npm test`에 질문 생성 및 친구 화면 검증이 포함됩니다. `tools/verify_battle.sql`은 트랜잭션 안에서 임시 사용자를 만들고 10·20·30문제 전체 진행, 조기 제출·정답 노출 방지, 중복 제출, 참여자 격리, 차단, 시간 초과, 중도 종료 및 권한을 검사한 뒤 롤백합니다.

배포 전 별도 임시 인증 계정 두 개로 실제 Edge API의 검색·친구 수락·문제 생성·준비·동시 답변·정답 공개·결과를 확인하고 계정을 삭제했습니다. Chromium에서 기존 앱 전체와 합친 화면을 320/360/390/768px로 확인했습니다. 실제 iOS 기기 두 대의 네트워크 환경은 별도로 확인하지 않았습니다.


## 대전 보상 (2026-09-25 도입)

- 10문제 기준 WIN 5P, DRAW 3P, LOSE 1P. 20·30문제는 2·3배.
- 경험치: 정답당 2 EXP + 완료 보너스 10문제당 5 EXP. 제한 시간과 무관.
- 한국 시간 하루 100문제, 상대별 첫 3판까지. 남은 한도만큼 앞 문제를 인정하며 비례 보상은 내림.
- 중도 포기자는 무보상. 상대는 이미 채점된 문제의 정답 경험치만 지급(승리 포인트/완료 보너스 없음).
- 일반 단어장 포인트는 해당 순위에, 학교 수행평가는 학생의 중등/고등 학년 그룹 단어장 순위에 합산.
- 도입 전 생성한 대전은 소급 지급하지 않음. 취소/만료된 대전은 무보상.
- `battle_rewards`의 대전/학생 기본키로 중복 지급 방지. status 전환 트리거에서 기존 `save_student_test_result_atomic`과 같은 트랜잭션으로 저장한다.
- `test_kind=battle` 학습기록과 기존 경험치 기록을 사용하므로 월간 순위/월간 우승자/레벨이 기존 집계에 함께 반영된다.
- RLS + service_role 전용 함수/테이블 권한. 프런트엔드가 보상액을 지정할 수 없다.
- 검증: `tools/verify_battle_rewards.sql`은 새 마이그레이션과 함께 BEGIN/ROLLBACK으로 감싸서 실행한다. 실제 보상 이력이 없는 격리된 트랜잭션을 전제로 한다. UI 검증은 기존 npm test에 포함.
